# Before making the repository public

- [ ] Verify you have permission to redistribute `YOLOv3TinyFP16.mlmodel`; check its original source and licence.
- [ ] Review code and Xcode settings for personal information and any confidential or university-restricted material.
- [ ] Open the project in Xcode, add any missing assets, and verify it builds on a compatible iOS SDK.
- [ ] Test the main features on a physical iPhone.
- [ ] Add screenshots or a short demo video only after checking that no private locations or other personal information are visible.
- [ ] Add an appropriate licence if you want to allow reuse.
- [ ] Create a new GitHub repository and upload the extracted project files (not the ZIP alone).
- [ ] Link the repository on your CV or LinkedIn once it is ready.
